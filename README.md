# Login Screen Tailwind

Uma tela de login responsiva desenvolvida como estudo prático de Tailwind CSS e
design mobile first.

## Sobre o projeto

A interface combina um formulário de autenticação limpo com uma composição
visual baseada em imagem. O layout se adapta a diferentes tamanhos de tela:
em dispositivos menores, o formulário ocupa toda a área disponível; em telas
maiores, a imagem e o formulário são exibidos lado a lado.

## Recursos

- Layout responsivo com abordagem mobile first
- Formulário com campos de e-mail e senha
- Opção para lembrar o acesso
- Links para recuperação de senha e cadastro
- Alternativa de login com Google
- Estados visuais de foco e interação nos controles
- Tipografia Poppins e paleta baseada em tons neutros e azul
- Imagem decorativa exibida exclusivamente em telas maiores

## Tecnologias

- HTML5
- Tailwind CSS
- Vite
- CSS
